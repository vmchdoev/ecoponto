# EcoPonto ♻️

Projeto acadêmico de Programação Web Front-End (Projeto 1 — HTML e CSS). O EcoPonto é um site educativo com orientações introdutórias sobre separação de resíduos e descarte consciente, relacionado aos Objetivos de Desenvolvimento Sustentável (ODS) 11 e 12.

## Páginas

- `index.html`: página principal do serviço.
- `cadastro.html`: formulário de cadastro com campos obrigatórios; após envio, encaminha para o login.
- `login.html`: formulário demonstrativo de e-mail e senha; após envio, encaminha para a página principal.
- `curriculo.html`: página provisória para substituir pelo currículo real do integrante.
- `css/style.css`: estilos e responsividade.
- `figs/`: pasta reservada para imagens locais, caso a equipe decida baixar e armazenar as imagens no repositório.

## Tecnologias

- HTML5 semântico
- CSS3
- Google Fonts (Manrope, DM Sans e Material Symbols Rounded)
- Sem frameworks

## Observações

Este protótipo não possui backend, autenticação real nem armazenamento de dados. Os formulários demonstram apenas a navegação entre páginas. As imagens ilustrativas são carregadas de URLs externas, então precisam de conexão com a internet. As informações sobre descarte são educativas; os dias, horários e materiais aceitos devem ser confirmados junto aos serviços oficiais de cada município.
